# Data Science Projects Portfolio

Проекты по обработке данных с использованием Python и Bash.

## 🛠 Стек технологий
* Python, Bash
* Обработка JSON, CSV, регулярные выражения
* Парсинг данных и синтаксический анализ

## 📂 Содержание
* **Bash_Data_Processing:** Скрипты для фильтрации, сортировки и обработки данных вакансий.
* **Python_Syntax_And_Semantics:** Задачи по парсингу данных акций, работе со словарями и шифрованию.
